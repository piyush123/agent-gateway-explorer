Agent Gateway Cross-Project Architecture Specification

Full architectural blueprint incorporating Shared VPC, Zero Trust mTLS/SPIFFE, Full-Duplex Egress/Ingress, SIEM Observability, and CI/CD lifecycle.

1. Executive Architectural Summary

The Centralized Cross-Project Agent Gateway establishes a single administrative, security, and observation hub in a dedicated Central Governance Project (Shared VPC Host). Spoke service projects deploy business agents and domain tools attached to shared subnets, routing all egress and ingress traffic through the central proxy with cryptographically attested SPIFFE identities.

2. Seven Pillar Comparison Matrix

Pillar Architectural Decision Implementation Details
Network Topology Shared VPC (Host Project) Central Governance project hosts the Shared VPC, Agent Gateways, and Envoy proxies. Spoke projects attach workloads to shared subnets.
Traffic Direction Full-Duplex (Ingress & Egress) Inbound client protection (CLIENT_TO_AGENT) and outbound MCP/tool calling governance (AGENT_TO_ANYWHERE).
Identity & Auth Zero Trust mTLS & SPIFFE Google Cloud CAS issues X.509 certs. IAP & Gatekeeper evaluate per-request CEL rules against caller SPIFFE URNs.
Observability Central SIEM + Sliced Spoke Sinks BigQuery/Chronicle captures all audit logs & verdicts. Filtered operational metrics and traces exported to respective spoke projects.
Tool / MCP Catalog Hybrid Tool Governance Central catalog for vetted enterprise tools + federated registration for spoke tools governed by central policies.
Data Protection Inline Policy-Driven DLP Inline Envoy filters enforce prompt injection defense, schema validation, and Cloud DLP masking.
Lifecycle Terraform / CI-CD Pipelines Spoke teams declare routes and reasoning engines via scoped cross-project IAM service accounts in CI/CD.
